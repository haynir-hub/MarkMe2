## 🎓 Technical Details (for reference):

**Problem Pattern:**
```python
def recursive_function(items, index):
    thread = Thread()  # Local variable
    thread.finished.connect(lambda: recursive_function(items, index+1))
    thread.start()
    # Function returns - thread reference lost!
```

**Solution Pattern:**
```python
class MainWindow:
    def __init__(self):
        self.current_thread = None
    
    def process_next(self):
        # Clean up previous
        if self.current_thread:
            self.current_thread.wait()
            self.current_thread.deleteLater()
        
        # Create new
        self.current_thread = Thread()
        self.current_thread.finished.connect(self.on_finished)
        self.current_thread.start()
    
    def on_finished(self):
        # Clean up
        self.current_thread.wait()
        self.current_thread.deleteLater()
        self.current_thread = None
        
        # Next
        QTimer.singleShot(100, self.process_next)
```
