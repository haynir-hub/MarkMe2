=== 🔵 תיקון מיקום העיגול ===

## מה עשיתי:
✅ הוספתי debug logging למיקום העיגול
✅ תיקנתי את ה-glow effect להיות חלול (לא ממולא)
✅ הוספתי בדיקת גבולות

---

## מה לעשות:

1. **סגור את התוכנה**

2. **הפעל מחדש:**
   ```
   לחץ כפול על: run.bat
   ```

3. **טען את אותו וידאו**

4. **נווט לפריים שבו רואים את השחקנית בצהוב**
   - אפשר להשתמש ב-Next/Previous Frame

5. **שלח לי screenshot:**
   - איפה העיגול עכשיו?
   - איפה הוא **צריך** להיות?

6. **שלח לי את הפלט מ-PowerShell:**
   - צריך לראות שורות כמו:
   ```
   _draw_circle: bbox=(x, y, w, h), center=(cx, cy), radius=r
   ```

---

## מה אני צריך לדעת:

1. **איפה ה-bbox?** (המלבן סביב השחקנית)
2. **איפה העיגול עכשיו?** (במרכז? למעלה? למטה?)
3. **איפה הוא צריך להיות?** (סביב הרגליים על הפרקט?)

---

## אפשרויות לתיקון:

### אם העיגול גבוה מדי (מעל הרגליים):
צריך להזיז את center_y למטה יותר:
```python
center_y = y + h + 10  # 10 פיקסלים מתחת לbbox
```

### אם העיגול נמוך מדי (מתחת לרגליים):
צריך להזיז את center_y למעלה:
```python
center_y = y + h - 10  # 10 פיקסלים מעל תחתית הbbox
```

### אם העיגול לא במרכז:
צריך לבדוק את center_x:
```python
center_x = x + w // 2  # אמור להיות במרכז
```
