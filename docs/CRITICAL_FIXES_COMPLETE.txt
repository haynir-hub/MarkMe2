**הבעיה:** Ring היה באמצע הגוף במקום סביב הרגליים

**הפתרון:**
```python
# חישוב מחדש של center_y:
# תחילה: חישוב radius
radius_x = max(int(w * 0.45), 20)
radius_y = max(int(w * 0.15), 8)

# אז: מרכז ליד תחתית bbox
center_y = y + h + int(radius_y * 0.3)
```

- src/render/modern_styles.py - draw_neon_ring, draw_pulse_circle, draw_gradient_ring
