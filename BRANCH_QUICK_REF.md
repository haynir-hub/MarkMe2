## 💻 Git Commands

### View All Branches
```bash
git branch -a
```

### Switch to Main Branch
```bash
git checkout main
```

### Switch to Feature Branch
```bash
git checkout feature/two-phase-tracking
```

### Update All Branches
```bash
git fetch origin
```

### View Branch Details
```bash
git remote show origin
```
