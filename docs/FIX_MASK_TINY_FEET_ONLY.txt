## ✅ התיקון:

**לפני:**
```python
# הסתיר 30% מהגובה - יותר מדי! ❌
feet_height = int(h * 0.3)
cv2.rectangle(mask, (x, feet_y), (x+w, y+h), 0, -1)
```

**אחרי:**
```python
# מסתיר רק 8% מהגובה - חתיכות קטנות! ✅
feet_height = max(int(h * 0.08), 8)  # Only 8%!
feet_y = y + h - feet_height
# רק האזור המרכזי שבו הרגליים (60% מהרוחב)
feet_width = int(w * 0.6)
feet_x = x + (w - feet_width) // 2
cv2.rectangle(mask, (feet_x, feet_y), (feet_x+feet_width, y+h), 0, -1)
```
