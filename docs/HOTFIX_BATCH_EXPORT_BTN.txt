=== 🔥 HOTFIX - Batch Export Button Crash ===

## ❌ הבעיה:

```
AttributeError: 'BatchPreviewDialog' object has no attribute 'export_btn'
```

**מתי:** כשניסית לעשות Export ל-5 סרטונים

**איפה:** src/ui/batch_preview_dialog.py - line 209

---

## 🔍 Root Cause:

הפונקציה `_update_summary()` נקראה **לפני** שה-`export_btn` נוצר!

**סדר הקוד הלא נכון:**
```python
# Summary
self.summary_label = QLabel()
layout.addWidget(self.summary_label)
self._update_summary()  # ❌ נקרא כאן - export_btn עדיין לא קיים!

# Export buttons
self.export_btn = QPushButton(...)  # נוצר כאן
```

---

## ✅ התיקון:

### 1. הזזתי את הקריאה ל-`_update_summary()`
**לפני:**
```python
# Summary
self.summary_label = QLabel()
layout.addWidget(self.summary_label)
self._update_summary()  # ❌ מוקדם מדי!

# Export buttons
self.export_btn = QPushButton(...)
```

**אחרי:**
```python
# Summary
self.summary_label = QLabel()
layout.addWidget(self.summary_label)

# Export buttons
self.export_btn = QPushButton(...)

# Update summary AFTER export_btn is created ✅
self._update_summary()
```

### 2. הוספתי בדיקה נוספת
```python
def _update_summary(self):
    # ...
    
    # Enable/disable export button (only if it exists)
    if hasattr(self, 'export_btn'):  # ✅ Safety check
        self.export_btn.setEnabled(approved_count > 0)
        # ...
```
