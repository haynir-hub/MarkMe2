## 🚀 איך להתחיל:

### 1. הפעל את התוכנה:
```
לחץ כפול על: run.bat
```

### 2. טען מספר סרטונים:
```
לחץ: ➕ Add Videos
בחר: 2-5 סרטונים
```

### 3. סמן שחקניות בכל סרטון:
```
לחץ על סרטון → Add Marker → צייר bbox → בחר סגנון
חזור על זה לכל סרטון
```

### 4. ייצא הכל בבת אחת!
```
לחץ: 📤 Export All Videos
בחר: תיקיית יעד
המתן: המערכת תעבד את כולם
```

### 5. קבל את התוצאה:
```
✅ Successful: X/Y videos
כל הסרטונים המיוצאים בתיקייה שבחרת!
```

## 🎯 תכונות מיוחדות:

### סטטוס ויזואלי:
```
⏸️ Pending - נטען, אין שחקנים
✏️ Marked - מסומן, מוכן לייצוא
🔄 Tracking - בתהליך
📤 Exporting - מייצא
🎬 Exported - הושלם!

⏭️ Skipped - דולג (אין שחקנים)

## 💡 דוגמה מלאה:

```
