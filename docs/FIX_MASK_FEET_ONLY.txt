=== 🔥 FIX - Mask חותך רק את הרגליים! ===

## ❌ הבעיה:

**המשתמש דיווח:**
"כל המאסקים שעשית חתכו הרבה יותר מדי"
"צריכים שיהיו חיתוכים רק את מה שהרגליים כביכול מסתירות"
"זה נראה רע מאוד עכשיו"

**הבעיה:**
ה-mask הסתיר את כל ה-bbox (כל הגוף), אבל החישוק נמצא על הריצפה - רק הרגליים צריכות להסתיר אותו!

---

## ✅ התיקון:

**לפני:**
```python
# Remove player bbox area from mask (player hides this part)
padding = 5
cv2.rectangle(
    mask,
    (x - padding, y - padding),  # ❌ כל הגוף!
    (x + w + padding, y + h + padding),
    0,
    -1
)
```

**אחרי:**
```python
# Remove only FEET area from mask (feet hide the ring, not whole body)
# Only the lower part of bbox (feet) should hide the ring
feet_height = int(h * 0.3)  # Bottom 30% of bbox (feet area)
feet_y = y + h - feet_height  # Start from bottom
padding = 3
cv2.rectangle(
    mask,
    (x - padding, feet_y - padding),  # ✅ רק הרגליים!
    (x + w + padding, y + h + padding),
    0,
    -1
)
```
