=== 🧪 הוראות בדיקה: Batch Processing ===

## ✅ מה לבדוק:

### שלב 1: הפעלה בסיסית
```
1. סגור את התוכנה (אם פתוחה)
2. לחץ כפול על: run.bat
3. בדוק שהחלון נפתח עם הממשק החדש:
   - "📹 Video List" בצד שמאל למעלה
   - "➕ Add Videos" כפתור
   - "👥 Players (Current Video)" באמצע
   - "🎬 Batch Export" למטה
```

### שלב 2: טעינת סרטונים
```
1. לחץ "➕ Add Videos"
2. בחר 2-3 סרטונים (לבדיקה)
3. בדוק:
   ✅ כל הסרטונים מופיעים ברשימה
   ✅ יש להם סמל ⏸️ (Pending)
   ✅ שם הקובץ + "(0 players)" מופיע
```

### שלב 3: סימון שחקנים בסרטון 1
```
1. לחץ על הסרטון הראשון ברשימה
2. הסרטון צריך להיטען לתצוגה
3. לחץ "➕ Add Marker"
4. צייר bounding box על שחקנית
5. בחר סגנון (למשל: "⭕ 3D Floor Hoop")
6. הקלד שם (למשל: "שחקנית 1")
7. לחץ Confirm

בדוק:
   ✅ השחקנית מופיעה ברשימת Players
   ✅ הסרטון ברשימה השתנה ל-✏️ Marked
   ✅ "(1 players)" מופיע
```

### שלב 4: סימון שחקנים בסרטון 2
```
1. לחץ על הסרטון השני ברשימה
2. הסרטון השני צריך להיטען
3. הוסף שחקנית אחת או יותר
4. בדוק שהסטטוס השתנה ל-✏️ Marked
```

### שלב 5: השאר סרטון ללא שחקנים
```
אם יש לך סרטון שלישי:
1. אל תוסיף לו שחקנים
2. הוא צריך להישאר ⏸️ Pending
זה יבדוק את הדילוג האוטומטי
```

### שלב 6: ייצוא Batch
```
1. לחץ "📤 Export All Videos"
2. בחר תיקייה לשמירה
3. המערכת צריכה להתחיל לעבד

בדוק במהלך:
   ✅ Progress bar זז
   ✅ הודעות בסטטוס: "🔄 Processing: ..."
   ✅ סרטונים ברשימה משנים סטטוס:
      ⏸️ → 🔄 Tracking → 📤 Exporting → 🎬 Exported
   ✅ סרטון ללא שחקנים מקבל ⏭️ Skipped

בסיום:
   ✅ חלון הודעה: "Batch Export Complete"
   ✅ "✅ Successful: X/Y videos"
   ✅ קבצים נוצרו בתיקייה שבחרת
   ✅ שמות: original_name_tracked.mp4
```

### שלב 7: בדוק את הקבצים המיוצאים
```
1. פתח את התיקייה שבחרת
2. צפה בסרטונים המיוצאים
3. בדוק:
   ✅ הסרטון מלא (לא תמונה סטטית)
   ✅ הסימונים עוקבים אחרי השחקניות
   ✅ העיגול/חץ/ריבוע ממוקם נכון
   ✅ האודיו מהמקור
```

## 🔍 בדיקות נוספות:

### בדיקה 1: הסרת סרטון
```
1. בחר סרטון ברשימה
2. לחץ "➖ Remove"
3. אשר את ההסרה
4. בדוק שהסרטון הוסר מהרשימה
```

### בדיקה 2: ייצוא סרטון בודד
```
1. בחר סרטון מסומן (✏️ Marked)
2. לחץ "📤 Export Current Video"
3. בחר שם קובץ
4. בדוק שרק הסרטון הזה מיוצא
```

### בדיקה 3: ניווט בין פריימים
```
1. בחר סרטון ברשימה
2. השתמש ב-Next/Previous Frame
3. בדוק שהפריימים משתנים
```

### בדיקה 4: סגירת תוכנה תקינה
```
1. סגור את התוכנה בזמן שיש פרויקטים פתוחים
2. בדוק שהתוכנה נסגרת בלי שגיאות
3. פתח שוב - הפרויקטים לא נשמרים (expected)
```

## ⚠️ מה לחפש:

### תקלות אפשריות:
❌ התוכנה לא נפתחת → שלח לי את השגיאה מ-PowerShell
❌ סרטון לא נטען → בדוק שהוא תקין (נגן אותו ב-VLC)
❌ Tracking נכשל → שלח screenshot + הודעת שגיאה
❌ Export נכשל → שלח את הפלט מ-PowerShell
❌ הסרטון המיוצא שגוי → שלח פרטים על הבעיה

### סימנים טובים:
✅ כל הכפתורים מגיבים
✅ הרשימות מתעדכנות
✅ הסטטוסים משתנים כראוי
✅ ה-Progress bar זז
✅ הקבצים המיוצאים תקינים
