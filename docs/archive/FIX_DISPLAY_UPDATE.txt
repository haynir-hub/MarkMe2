## הפתרון:
תיקנתי את `VideoCanvas._update_display()` בשלוש דרכים:

### 1. Deep Copy של QImage
```python
rgb_frame_copy = rgb_frame.copy()
qt_image = QImage(rgb_frame_copy.data, ...)
qt_image = qt_image.copy()  # Deep copy
```
**למה:** כדי שהמידע לא יידרס כשהזיכרון משתחרר

### 2. הוספת update() + repaint()
```python
self.update()  # Force widget update
self.repaint()  # Force immediate repaint
```
**למה:** לאלץ את הווידג'ט לצייר מחדש מיד

### 3. הוספת processEvents()
```python
QApplication.processEvents()  # Process pending GUI events
```
**למה:** לוודא שכל העדכונים של ה-GUI מעובדים מיד
