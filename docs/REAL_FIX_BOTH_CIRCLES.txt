## ✅ מה תיקנתי עכשיו:

### 1️⃣ video_canvas.py (העיגול הראשוני):
```python
# לפני - עיגול עגול רגיל:
center_y = sy + sh
radius = max(sw // 2, 10)
painter.drawEllipse(...)

# אחרי - אליפסה תלת-ממדית:
radius_x = max(int(sw * 0.65), 30)
radius_y = max(int(sw * 0.22), 10)
center_y = sy + sh - radius_y
painter.drawEllipse(center_x - radius_x, center_y - radius_y, radius_x * 2, radius_y * 2)
```

### 2️⃣ overlay_renderer.py (העיגול בtracking):
```python
center_y = y + h - radius_y
```
