=== 🎯 תיקון מיקום העיגול - השחקנית במרכז ===

## מה עשיתי:

### 1️⃣ הגדלת ה-Smoothing Buffer (PlayerTracker)
✅ שיניתי מ-5 ל-**10 פריימים**
- המיצוע מתבצע על 10 פריימים אחרונים במקום 5
- זה גורם לתנועה חלקה יותר ופחות "קפיצות"
- ה-bbox יהיה יותר יציב

### 2️⃣ שיפור חישוב מרכז העיגול
✅ **מיקום אנכי (Y):**
- לפני: `center_y = y + h` (תחתית ה-bbox בדיוק)
- עכשיו: `center_y = y + h - (h * 0.02)` (2% מעל התחתית)
- זה מבטיח שהעיגול ממוקם מדויק יותר סביב הרגליים

✅ **גודל העיגול:**
- הגדלתי מעט את הרדיוסים (65% ו-22% במקום 60% ו-20%)
- העיגול יהיה קצת יותר גדול ובולט
- יותר טוב להכיל את השחקנית במרכזו

### 3️⃣ הוספת Debug Logging
✅ העיגול ידפיס מידע כל כמה פריימים:
```
🎯 Circle: bbox=(x, y, w, h) → center=(cx, cy), radius=(rx, ry)
```

## אם עדיין יש בעיה:

### אופציה 1: העיגול "קופץ" או לא חלק
→ זו בעיה של ה-tracking עצמו (OpenCV tracker)
→ אפשר להגדיל את ה-smoothing buffer עוד יותר (ל-15 או 20)

### אופציה 2: העיגול לא ממורכז (יותר מדי שמאלה/ימינה)
→ צריך לכוונן את `center_x = x + w // 2`
→ אולי להוסיף offset: `center_x = x + w // 2 + offset_x`

### אופציה 3: העיגול גבוה מדי או נמוך מדי
→ צריך לכוונן את `center_y = y + h - (h * 0.02)`
→ אולי לשנות את 0.02 ל-0.05 או 0.10
