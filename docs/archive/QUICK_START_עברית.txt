## 💨 בדיקה מהירה - 3 דקות:

### 1. **פתח מחדש:**
```
Ctrl+C  (סגור)
לחץ כפול: run.bat
```

### 2. **טען סרטון:**
```
➕ Add Videos
בחר סרטון קצר (10-30 שניות)
לחץ על הסרטון ברשימה
```

### 3. **סמן עם סגנון מודרני:**
```
➕ Add Marker
צייר bbox על שחקנית
גלול למטה ב-"Marker Style":
  
💫 Pulse Circle       ← מומלץ! אנימציה פועמת
💠 Neon Ring          ← זוהר מרהיב
🌈 Gradient Ring      ← צבעוני
🎯 Dynamic Arrow      ← קופץ משעשע
⬡ Hexagon            ← פיוטריסטי
🎮 Crosshair         ← גיימינג

Confirm
```

### 4. **נסה Preview + Export:**
```
📤 Export Current Video
↓
🔄 Track (אוטומטי אם צריך)
↓
📺 Preview נפתח!
↓
▶ Play (Space) → בדוק
🖵 Fullscreen (F11) → מסך מלא
←→ חצים → ניווט
↓
✅ "I approve..."
📤 Proceed to Export
💾 בחר מיקום
↓
⚡ ייצוא מהיר! (15-30 שניות)
```
