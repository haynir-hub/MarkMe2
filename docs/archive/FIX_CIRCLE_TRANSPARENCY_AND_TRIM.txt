## ✅ התיקונים:

### 1. תיקון שקיפות העיגול

**לפני:**
- עיגול גדול (50% מהרוחב)
- opacity גבוה (0.5-0.8)
- מסתיר את הסרטון

**אחרי:**
- עיגול קטן יותר (35% מהרוחב במקום 50%)
- opacity נמוך יותר (0.4-0.6)
- יותר שקוף - לא מסתיר את הסרטון

**קבצים ששונו:**
- `src/render/overlay_renderer.py` - Circle style
- `src/render/modern_styles.py` - Neon Ring, Pulse Circle, Gradient Ring

### 2. הוספת Trim Feature

**מה נוסף:**
1. **UI לסמן Trim:**
   - כפתור "📍 Set Start" - מסמן נקודת התחלה
   - כפתור "📍 Set End" - מסמן נקודת סיום
   - כפתור "🗑️ Clear" - מנקה את ה-trim
   - תצוגה של ה-trim range

2. **שמירת Trim בפרויקט:**
   - `trim_start_frame` - frame התחלה (None = מההתחלה)
   - `trim_end_frame` - frame סיום (None = עד הסוף)

3. **שימוש ב-Trim במעקב:**
   - המעקב עובד רק על הטווח שנבחר
   - אם לא נבחר trim, עובד על כל הסרטון

**קבצים ששונו:**
- `src/tracking/video_project.py` - הוספת trim_start_frame, trim_end_frame
- `src/ui/main_window.py` - UI + פונקציות Trim + שימוש ב-trim במעקב
- `src/ui/main_window.py` - TrackingThread מקבל trim range
