=== ✅ תיקון סופי - tracker.init() מחזיר None ===

## הבעיה שמצאתי:
```
tracker.init() returned: None
❌ tracker.init() returned False!
```

ה-`tracker.init()` מחזיר `None` במקום `True`/`False`!
זו בעיה ידועה עם הAPI של opencv-contrib-python 4.12.0.

## התיקון:
✅ אם `init()` מחזיר `None` - מנסה מחדש עם **legacy API**
✅ בדיקה שה-bbox בתוך גבולות הפריים
✅ Clamping של bbox אם הוא חורג
✅ ניסיון עם legacy API קודם (יותר אמין)
