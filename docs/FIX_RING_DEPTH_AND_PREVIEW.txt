=== 🔥 FIX - Ring Depth & Preview Crash ===

## ✅ תיקונים:

### 1. Ring Depth - השחקנית מסתירה את החלק האחורי! ✅

**הבעיה:**
החישוק היה מצויר מעל השחקנית - לא נראה כאילו השחקנית עומדת בין המצלמה לחישוק.

**הפתרון:**
שימוש ב-mask כדי להסתיר את החלק האחורי של החישוק (180-360 מעלות) באזורים שהשחקנית מסתירה.

**איך זה עובד:**
1. יוצר mask של החלק האחורי של החישוק
2. מסיר מהמסכה את האזור של ה-bbox (השחקנית)
3. מצייר את החלק האחורי רק על המסכה (רק החלקים הגלויים)
4. מצייר את החלק הקדמי כרגיל (0-180 מעלות)

**תוצאה:**
עכשיו נראה כאילו השחקנית עומדת בין המצלמה לחישוק - החלק שמאחוריה מוסתר!

### 2. Preview Crash - תוקן! ✅

**הבעיה:**
```
AttributeError: 'MainWindow' object has no attribute '_show_preview_for_project'
```

**הסיבה:**
הפונקציה `_show_preview_for_project` הוגדרה כפונקציה מקומית (nested function) בתוך `on_tracking_complete`, אבל נקראה כ-`self._show_preview_for_project(project)`.

**התיקון:**
שינוי הקריאה לשימוש ישיר בפונקציה המקומית: `_show_preview_for_project(project)`

**קובץ:** src/ui/main_window.py - שורה 562

**לפני:**
```python
if reply == QMessageBox.StandardButton.Yes:
    self._show_preview_for_project(project)  # ❌
```

**אחרי:**
```python
if reply == QMessageBox.StandardButton.Yes:
    _show_preview_for_project(project)  # ✅
```
