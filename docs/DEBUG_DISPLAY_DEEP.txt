```python
qt_image = QImage(rgb_frame.data.tobytes(), ...).copy()
```
כדי לוודא שהנתונים באמת מועתקים ולא רק מצביע.

### 2. בדיקת Widget Status
```python
Widget visible=?, enabled=?
Widget size=?
```
כדי לראות אם ה-widget בכלל נראה ופעיל.

### 3. בדיקת Pixmap לפני ואחרי
```python

```
כדי לוודא שה-pixmap באמת משתנה.

### 4. scaled_pixmap.copy()
כדי לוודא שהוא לא shared.

## מה אני מחפש:

### בדיקה 1: Widget Status
```
_update_display: Widget visible=True, enabled=True
_update_display: Widget size=PyQt6.QtCore.QSize(640, 360)
```
אם False - הבעיה היא שה-widget מוסתר!

### בדיקה 2: Pixmap Changes
```
_update_display: Old pixmap size: PyQt6.QtCore.QSize(936, 527)
_update_display: ✅ New pixmap set successfully, size=PyQt6.QtCore.QSize(936, 527)
```
אם הגודל לא משתנה בין פריימים - יש בעיה.

### בדיקה 3: QImage Valid
```
_update_display: QImage created and copied: PyQt6.QtCore.QSize(1920, 1080)
```
אם ERROR: QImage is null - בעיה ביצירת התמונה.
