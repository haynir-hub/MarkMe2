---

## 📐 הנוסחה החדשה:

```python
center_y = feet + radius_y
```

### למה?
```
רגליים נמצאות ב: y + h
מרכז העיגול: y + h + radius_y  ← מתחת לרגליים!

→ קצה עליון: (y + h + radius_y) - radius_y = y + h  ← רגליים כאן!
→ מרכז: y + h + radius_y
→ קצה תחתון: y + h + 2*radius_y  ← על הרצפה
```

**תוצאה:** רגליים בקצה העליון של העיגול!
