=== 🎬 מדריך: Batch Processing - עיבוד מספר סרטונים ===

## ✅ מה נוסף:

### 1️⃣ מבנה חדש למערכת:
✅ **VideoProject** - מייצג פרויקט סרטון בודד עם:
   - מטא-דאטה (רזולוציה, FPS, משך)
   - רשימת שחקנים לעקוב
   - תוצאות tracking
   - סטטוס (pending, marked, tracked, exported, failed)

✅ **ProjectManager** - מנהל מספר פרויקטים:
   - הוספה והסרה של סרטונים
   - ניהול הפרויקט הנוכחי
   - זיהוי פרויקטים מוכנים לייצוא

✅ **BatchExportThread** - עיבוד אצווה:
   - עובר על כל הסרטונים ברצף
   - מבצע tracking + export לכל סרטון
   - מדלג על סרטונים ללא שחקנים
   - מדווח על הצלחה/כישלון

### 2️⃣ ממשק משתמש חדש:

📹 **רשימת סרטונים (Video List):**
   - מציג את כל הסרטונים שנטענו
   - סטטוס סמלים:
     ⏸️ Pending - נטען, אין שחקנים
     ✏️ Marked - יש שחקנים, מוכן ל-tracking
     ✅ Tracked - tracking הושלם
     🎬 Exported - ייצוא הושלם
     ❌ Failed - נכשל
     ⏭️ Skipped - דולג (אין שחקנים)

👥 **רשימת שחקנים (Players):**
   - מציגה שחקנים של הסרטון הנוכחי
   - כל סרטון יכול לקבל שחקנים שונים

🎬 **כפתורי ייצוא:**
   - "Export All Videos" - מייצא את כל הסרטונים ברצף
   - "Export Current Video" - מייצא רק את הסרטון הנוכחי

---

## 📋 תהליך העבודה החדש:

### שלב 1: טען סרטונים 📹
```
1. לחץ על "➕ Add Videos"
2. בחר מספר סרטונים (MP4, MOV, MKV, WEBM)
3. כל הסרטונים יופיעו ברשימה עם סטטוס ⏸️ Pending
```

### שלב 2: סמן שחקנים בכל סרטון 👥
```
לכל סרטון:
1. לחץ על הסרטון ברשימה
2. הסרטון יטען לתצוגה
3. לחץ "➕ Add Marker"
4. צייר bounding box על שחקנית
5. בחר סגנון סימון (Circle, Arrow, Rectangle, Spotlight, Outline)
6. הקלד שם (אופציונלי)
7. לחץ Confirm

הסרטון יקבל סטטוס ✏️ Marked
```

### שלב 3: ייצוא אצווה 🎬
```
אופציה א' - ייצוא כל הסרטונים:
1. לחץ על "📤 Export All Videos"
2. בחר תיקיית יעד
3. המערכת תעבור על כל הסרטונים:
   - תבצע tracking אוטומטית
   - תייצא עם הסימונים
   - תדלג על סרטונים ללא שחקנים
   - תדווח על כישלונות

אופציה ב' - ייצוא סרטון בודד:
1. בחר סרטון ברשימה
2. לחץ "📤 Export Current Video"
3. בחר שם קובץ
4. הסרטון יישמר עם הסימונים
```

---

## 🔍 מה קורה בעת ייצוא אצווה:

### לכל סרטון:
1. ✅ בודק אם יש שחקנים מסומנים
2. ⏭️ אם אין - דולג עליו
3. 🔄 מבצע tracking אוטומטי על כל הפריימים
4. 📤 מייצא סרטון עם הסימונים
5. ✅ מסמן כ-Exported
6. ❌ אם נכשל - מסמן כ-Failed ושומר הודעת שגיאה

### בסיום:
```
תקבל דו"ח:
✅ Successful: X/Y videos
❌ Failed: X/Y videos
```

## 💡 טיפים:

### ✅ עבודה יעילה:
1. **טען את כל הסרטונים בבת אחת** - חסוך זמן
2. **סמן שחקנים לפני ייצוא** - הייצוא יעשה tracking אוטומטית
3. **השתמש באותו סגנון** - קל יותר לזהות שחקניות

### ⚠️ התראות:
- **סרטונים ללא שחקנים** - ידלגו אוטומטית, תקבל הודעה
- **סרטונים שנכשלו** - יסומנו ב-❌ עם הסבר הבעיה
- **מהירות** - ייצוא יכול לקחת זמן (תלוי במספר הסרטונים)

### 📁 קבצי פלט:
```
כל סרטון נשמר כ:
original_name_tracked.mp4

בתיקייה שבחרת
```

```
1. טען 5 סרטונים:
   - game1.mp4 ⏸️
   - game2.mp4 ⏸️
   - game3.webm ⏸️
   - game4.mov ⏸️
   - game5.mp4 ⏸️

2. סמן שחקנים:
   - game1: 2 שחקניות ✏️
   - game2: 1 שחקנית ✏️
   - game3: אין שחקנים ⏸️ (נדלג)
   - game4: 3 שחקניות ✏️
   - game5: אין שחקנים ⏸️ (נדלג)

3. לחץ "Export All Videos"
   בחר תיקייה: C:\Output

4. המערכת תעבד:
   ✅ game1_tracked.mp4 (2 שחקניות)
   ✅ game2_tracked.mp4 (1 שחקנית)
   ⏭️ game3 (דולג - אין שחקנים)
   ✅ game4_tracked.mov (3 שחקניות)
   ⏭️ game5 (דולג - אין שחקנים)

5. תוצאה:
   ✅ Successful: 3/5
   ⏭️ Skipped: 2/5
```

## 🐛 פתרון בעיות:

### בעיה: סרטון נכשל (❌ Failed)
**פתרון:**
1. בחר את הסרטון ברשימה
2. בדוק את הודעת השגיאה בפרטי הסרטון
3. סיבות נפוצות:
   - קובץ פגום
   - קודק לא נתמך
   - tracking לא הצליח

### בעיה: המערכת לא מגיבה בזמן ייצוא
**תשובה:** זה תקין!
- הייצוא רץ ב-background
- עקוב אחרי ה-progress bar
- אל תסגור את התוכנה
- המתן לסיום

### בעיה: רוצה לבטל ייצוא
**פתרון:** כרגע אין cancel - המתן לסיום
(אפשר להוסיף בעתיד)

## 📝 הערות חשובות:

### ✅ יתרונות המערכת החדשה:
- עיבוד מספר סרטונים בבת אחת
- חיסכון בזמן (לא צריך לטפל בכל אחד בנפרד)

### 🔮 תכונות עתידיות אפשריות:
- Parallel export (ייצוא מקבילי)
- Resume from failure (המשך אחרי כישלון)
- Auto-save projects (שמירת פרויקטים)
- Batch settings (הגדרות לכל האצווה)
