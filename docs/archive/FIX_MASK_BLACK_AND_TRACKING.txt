## ✅ תיקון 1: Mask Black Screen

**הבעיה:**
```python
overlay = cv2.bitwise_and(overlay, overlay, mask=mask)  # ❌ לא עובד עם BGR
```

**התיקון:**
```python
# Create 3-channel mask for proper blending
mask_3channel = cv2.cvtColor(mask, cv2.COLOR_GRAY2BGR) / 255.0
overlay = (overlay * mask_3channel + frame * (1 - mask_3channel)).astype(np.uint8)
```
