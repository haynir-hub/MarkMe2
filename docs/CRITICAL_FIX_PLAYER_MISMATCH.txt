=== 🔥 CRITICAL FIX - Player Mismatch in Export ===

## ❌ הבעיה הקריטית:

**המשתמש דיווח:**
- ב-Preview: השחקנית הנכונה מופיעה ✅
- ב-Export: השחקנית הלא נכונה מופיעה ❌
- זו לא השחקנית שסימן - זו שחקנית אחרת!

**זה באג קריטי!** המערכת עוקבת אחרי השחקנית הלא נכונה ב-export!

---

## 🔍 Root Cause Analysis:

### הבעיה האפשרית:

1. **סדר Players לא קבוע:**
   - `get_all_players()` מחזיר `list(self.players.values())`
   - הסדר תלוי בסדר ה-insertion ל-dict
   - אם יש כמה players, הסדר יכול להשתנות

2. **Player ID Mapping:**
   - אם ה-player_id משתנה או לא נשמר נכון
   - ה-tracking_results יכולים להיות משויכים ל-player הלא נכון

3. **Tracking Results Storage:**
   - אם ה-tracking_results נמחקים או משתנים לפני export
   - ה-export יכול להשתמש ב-data לא נכון

## ✅ התיקונים שיישמתי:

### 1. Sorting Players by ID
**קובץ:** src/tracking/tracker_manager.py

**לפני:**
```python
def get_all_players(self) -> List[PlayerData]:
    return list(self.players.values())  # ❌ לא ממוין
```

**אחרי:**
```python
def get_all_players(self) -> List[PlayerData]:
    return sorted(list(self.players.values()), key=lambda p: p.player_id)  # ✅ ממוין
```

**למה זה חשוב:**
- עכשיו הסדר תמיד זהה - לפי player_id
- Preview ו-Export משתמשים באותו סדר
- אין בלבול בין players

### 2. Enhanced Logging in Export
**קובץ:** src/render/video_exporter.py

**הוספתי:**
- Logging של player_id, name, bbox, style ב-frame הראשון
- Warning אם bbox חסר
- זה יעזור לזהות את הבעיה אם היא עדיין קיימת

### 3. Enhanced Logging in Preview
**קובץ:** src/ui/preview_dialog.py

**הוספתי:**
- Logging של player_id, name, bbox, style ב-frame הראשון
- זה מאפשר להשוות בין preview ל-export
